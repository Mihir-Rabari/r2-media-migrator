# Test traceability matrix

Each reference has the form `` `file :: fragment` ``: the file must exist and contain the fragment (literal substring of a
test title or assertion). `tests/unit/traceability.test.ts` **fails the build if any reference is stale**, so this table
cannot silently rot. Statuses (PASS / FAIL / NOT RUN) for the latest execution are in `validation-results.md`.
